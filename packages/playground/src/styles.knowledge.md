# Color Standards

## Text Colors
- Titles/Headings: Use `text-title` (#FFFFFF, white)
- Body text: Use `text-text` (#808080, gray)

## Usage
- All headings (h1, h2, h3, etc.) should use `text-title`
- All regular text content should use `text-text`
- Avoid using raw color values - use the defined color classes instead
